Antigravity accounts

Each account runs the official agy CLI in its own home directory. CLIProxyAPI rotates requests between enabled accounts.

Management key

This page could not read the management key from the CLIProxyAPI panel. Enter it to continue. It is kept only for this browser tab.

Add an Antigravity account

  1. Open Google sign-in and sign in with the account you want to add.
  2. You end up on an antigravity.google page. Copy that page's full URL from the address bar (or the code it shows) and paste it here.
